# Gavin Lake public benchmarks

## Klinka 2004 site index

`data/site_index/klinka_2004_site_index.csv` transcribes Klinka et al. 2004
Tables 8.2.1–8.2.4. The Gavin Lake block is in the SBSdw1 and ICHmk3 units; the
Knife Creek IDFxm/IDFdk3 rows are included for the sibling instance.

The values are potential site index (metres at 50 years breast height), not a
measured Gavin growth curve. They are useful for checking the site-index
assumptions behind the legacy yield curves, not for replacing the legacy H
matrix.

## MWP #3 Gavin Lake Demonstration Area AAC

`data/benchmarks/mwp3_gavin_aac.csv` records the Gavin Lake Demonstration Area
(GL) values from AFRF Management and Working Plan #3 Tables 34 and 36:

| Item | Value |
| --- | ---: |
| Net area | 532 ha |
| Net harvest land base | 478 ha |
| Cutting cycle | 100 years |
| AAC clearcut | 2.4 ha/year |
| AAC partial cut | 3.0 ha/year |
| AAC salvage | 2.4 ha/year |
| AAC total (GL) | 7.8 ha/year |
| Actual 2001–2005 clearcut | 7.1 ha/year |
| Actual 2001–2005 partial cut | 14.2 ha/year |
| Actual 2001–2005 salvage | 10.5 ha/year |
| Actual 2001–2005 total (GL) | 31.8 ha/year |

The GL working circle is much smaller than the legacy Gavin model's 4,662.96 ha
productive THLB proxy, and its 100-year cycle is not the legacy 80-year
clearcut rotation. The values are a public management-plan benchmark, not the
legacy Patchworks scenario intent. Do not use the Table 36 “Total Gavin” row
(132.7 / 74.4 ha/year) as a GL benchmark; it includes Beaver Valley, Gavin Lake
and the Timber Production Area.

## What was not recovered

- MWP #3 Figure 11 is the Knife Creek mule-deer winter-range target structure.
  It is not a Gavin benchmark.
- MWP #3 Figures 5, 12, 13 and 14 are forest-wide or working-circle stacked
  bars. The exact values are in Tables 34–36, so the tables are the better
  source. No figrecover pass was needed for Gavin.
- Klinka 2004's quantitative content is in its tables, not its photo figures.
- The MWP #3 maps are schematic planning maps without coordinate grids; they
  were not georeferenced.

## Source caveats

The plan is a public UBC AFRF planning document, not OGL. It is a management
plan, not a legal order. The Gavin legacy dataset remains the primary scenario
source; these tables are reference and cross-check material.
