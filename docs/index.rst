AFRF Gavin Lake Instance
========================

A **ws4 forest-estate model instance** for the Gavin Lake block of the UBC Alex
Fraser Research Forest (AFRF).

The instance translates the legacy AFRF Patchworks H matrix into a ws4-native
compiled dataset, keeps the legacy package as a benchmark reference, and
records the structural parity evidence. The ws4 dataset is the runtime lane;
Patchworks is the reference lane.
