# Gavin Lake roads

`gavin_public_roads.gpkg` is the public BC Forest Tenure road-section layer
clipped to the Gavin Lake fragment union.

- 69 features, merged into 193 route segments.
- 19.3 km of public road.
- The 2007 plan records 112.2 km of existing roads, so the public layer is
  incomplete by about 93 km.

This layer is map and route context only. It is not a field-verified AFRF road
inventory, a legal access determination, or a complete access network.
